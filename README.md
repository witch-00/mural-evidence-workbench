# 壁画智护 · 可复核的壁画观察与虚拟修复

参赛产品设计，面向第二届北京市大学生“人工智能+”创新大赛阿里云壁画赛题。区域证据卡、SQLite 工作档案与紧凑图像工作区已接入现有壁画工作台，支持自动保存、历史版本、专业文献建议及单页 PDF。仓库包含前端源码、观察卡和档案模块、服务端集成补丁及回归测试。

从一处可见的图像现象出发，保留它在原图上的位置、判断依据、AI 初稿和人工修订。在线上将同一次操作导出为一页观察卡。到现场使用新发材料和赛事指定平台，解释哪些地方可以尝试虚拟修复、哪些地方应保留缺失。
