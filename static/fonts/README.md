# 观察卡宋体

PDF 使用 Mural Serif SC Regular 与 Semibold，分别用于正文与主次标题。两份 TTF 均嵌入 PDF 的字形子集，接收者无需安装字体。

字体源于 [Noto Serif SC 2.003](https://github.com/notofonts/noto-cjk/blob/main/Serif/README.md)，版权 © 2017–2024 Adobe，依 SIL Open Font License 1.1 分发，完整许可证见 MuralSerifSC-OFL.txt；原版权信息保留在字体内部。原始变量字体下载地址为 `https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/Variable/TTF/Subset/NotoSerifSC-VF.ttf`。

本项目将 wght 轴固定为 400、600，保留原字体全部 Unicode 映射，名称改为 Mural Serif SC，以区分派生文件。原始下载文件 SHA-256：`5326cfb097e3ab26fcb39329752b5c0a439bf8d5c4649520e4b492939c352a09`。无需在运行环境安装字体构建工具。界面原有本机字体设置继续由浏览器使用。
