# 在 Ubuntu 上接入现有工作台

此增量适用于已取得原壁画工作台源码的团队，验证基线为 cf2be17。建议在独立工作副本上安装，保留原实例及未保存的浏览器进度。

在本仓库根目录，设置 BASE 为原工作台工作副本的绝对路径，再运行：

```bash
git -C "$BASE" apply --check "$PWD/integration/workbench.patch" &&
git -C "$BASE" apply "$PWD/integration/workbench.patch" &&
cp static/region-evidence.js static/region-evidence.css static/workspace.js static/workspace.css static/repair-controls.js static/comparison-view.js static/case-library.js static/advice-sources.js static/library.css "$BASE/static/" &&
cp -R static/vendor "$BASE/static/" &&
cp observation_card.py case_store.py case_api.py recommendation_sources.py "$BASE/" &&
cp -R references "$BASE/" &&
cp static/fonts/MuralSerifSC-* "$BASE/static/fonts/" &&
cp model-config.html "$BASE/" &&
cp static/model-config.css "$BASE/static/"
```

使用原工作台配置的 Python 环境及依赖。在 BASE 目录运行 `python -m flask --app app run --host 127.0.0.1 --port 8766`，浏览器打开 http://localhost:8766 。实例只监听回环地址，适合同一台电脑轮流试用。模型凭据继续由原工作台的配置机制管理。替换 Python 文件后重启该实例。

在本仓库根目录，用含原工作台测试依赖的 Python 运行 `PYTHONPATH="$BASE" python -m unittest discover -s tests`。工作文件 v1/v2 可恢复后补录依据；新文件使用 v3，保留每个区域的引用和复核记录。观察卡接口支持旧版输入，并统一使用新版宋体表格。

工作台导入框可选择 JPEG、PNG、WebP 图片或 JSON 工作文件。若要启用一键试用，将可供本机队员查看的练习工作文件放在工作副本的 `sample/evidence-trial.json`；首页会显示“打开试用工作文件”，也可直接访问 `/?trial=evidence`。

导入新图片后，“图像与资料”保持展开，便于继续填写图片来源与授权、参考资料和背景说明。填写完成后可手动折叠。

## SQLite 工作档案

主页“保存到档案／打开档案”使用实际 SQLite 存储。编辑后会延迟自动保存并显示状态；普通主页可以恢复上次打开的档案，带 `trial` 的网址仍明确载入示例。打开历史版本会创建编辑副本；不同页面写同一版本返回冲突，可另存副本或重新打开，保留各自内容。

默认存储在 BASE/data/case-library/workbench.sqlite3，图像以 SHA-256 命名放在同目录 assets/；设置 MURAL_DATA_DIR 可以换到其他持久目录。数据库和 assets 共同构成档案库，不能只复制数据库作为完整图像备份。需要直接备份整个目录时先停止服务；单份档案也可导出 JSON 工作文件。数据库目录保持私有并已排除在 Git 之外。此版本没有删除档案的入口。

SQLite 表记录案例、不可变版本、去重图像索引和逐条引用快照。保存失败回滚数据库事务，页面保留编辑并允许导出工作文件。恢复图像时检查指纹。使用标准库 sqlite3，无新增数据库服务或 ORM 依赖。

档案恢复与新图导入统一采用8000万像素上限，工作文件总大小上限与服务端的480 MiB请求限制一致，避免已保存的大图被旧版较低的恢复上限挡住。

## 有出处的建议

“建议与文献”面板中，每条建议可打开“从权威文献选择建议”，在保护、数字展示、公众传播三类中选择。当前目录包含两部已核对全文的 Getty 专业图书、ICOMOS 2003/2008 准则、中国文物古迹保护准则2015版与 London Charter 2.1，共6个来源、6条模板。

模板提供行动、文献原则和风险，本图依据单独填写。正式卡保留1–2条。新格式导出要求行动、风险和引用仍与已核对模板相符，防止把任意改写内容套上书目编号。PDF 的建议表含引用编号与定位，来源区列书目和可点击全文。详见 [逐条来源核对](../docs/research/recommendation-sources-2026-11-21.md)。

## API 配置与本机代理兼容

`/model-config` 使用独立的朱红宋体样式，表单与说明分栏，窄屏改为单列。测试连接与保存继续使用原工作台的 `static/model-config.js` 和服务端凭证校验。

如果本机的 TUN 代理将公开 API 域名解析为 198.18.0.0/15，需要额外应用 `integration/network-compat.patch`。先在原工作副本运行 `git apply --check`，再应用；启动时用 `MURAL_FAKE_IP_HOSTS=api.deepseek.com` 按实际需要列出精确域名。普通网络无需此项。该兼容只放行列明域名的代理地址池，仍拒绝私网目标，保留原主机名 TLS 验证与已检查地址绑定。此补丁包含对应的回归测试，不包含实际 Key 或已保存的配置。


## 界面与字体

观察区使用定高分栏，区域按钮切换当前编辑项，保护建议在独立面板编辑。裁片弹窗采用原生 dialog，图片按自身比例显示，说明独立滚动；Panzoom 4.6.2 支持缩放和平移。修复区可切换局部与全图，并放大并排核对。新图片在 LaMa 可用且允许时默认选择它，恢复的工作文件保留其处理方法。

字体优先使用队员电脑已经安装的方正书宋简体和华文楷体，依次回退到华文宋体、宋体、楷体及系统衬线字体。字体文件由各自设备提供。公开仓库包含 CSS 字体配置，Panzoom 的 MIT 许可证与发行文件位于同一目录。

2026 年 11 月 20 日，用 1440、1024、390 像素视口验证了区域切换、建议面板、弹窗裁片尺寸、缩放、关闭按钮与页面溢出。另从浏览器实际调用 LaMa 处理合成图的跨边框区域，验证范围外像素一致、局部/全图切换与单页报告导出。该合成测试反映此例的工程行为，真实题图逐处复核后采纳。


## 修复方法的入口

| 常用按钮 | 实际处理 | 选用时机 |
|---|---|---|
| 自动补全 | LaMa 根据邻近画面补画 | 线条、色块交错的小范围缺损，生成后检查是否新增内容 |
| 借用原图 | 人工选一处完好图案，再按缺口形状复制与融合 | 同图中有大小、方向相近的重复花纹 |
| 细缝填色 | OpenCV Telea 从附近颜色填充 | 窄裂缝或单色区域；复杂花纹要检查模糊情况 |
| 百炼重绘 | 通过百炼调用图像生成能力 | 已配置相应百炼权益，需要云端重绘 |

原有按形状处理、分层填补、纹理比对、补全后匹配纹理，集中放在“其他处理方法”按钮区，旧工作文件保留原算法编号。界面合并的是选择入口，已有方法仍可复现。

“借用原图”的操作示例是涂住破损圆花，再点同图另一朵完好圆花的中间。程序以这一点为中心，截取与修补范围相应大小的来源块。可先让程序推荐位置，再对照绿框确认。导出缺项会跳回具体区域和输入项。

## 观察卡与本次结论

卡片采用宋体正文与加粗宋体标题，分原图、区域记录、建议与风险、来源与 AI 参与四部分。图像保留比例，局部图加入原图周边以方便定位。观察与依据、建议与风险各自成表，字号按内容量在 9–9.5 pt 之间选择；信息超出单页承载量时提示精简，完整记录仍可保存为 JSON。顶部来源图例与“已人工复核”的认证式字样已移除。

参考北齐的“明确选项与审批意见”方式，本版本由当前操作者完成四选一，不引入审核员账号或等待审批状态。

| 本次结论 | 操作与导出行为 |
|---|---|
| 采纳描述 | 选择原图特征相符、资料相符或其他理由，登记具体依据 |
| 修改后采纳 | 实际修改描述，选择原描述推断过度、纹样或画质等理由，再登记依据 |
| 不采纳 | 选择未见所述异常、原有纹样等理由；卡片显示原文未被采纳 |
| 本图无法判断 | 选择分辨率不足、成因无法判定等理由，完成本次记录，无后续审核状态 |

依据类型为原图对照、资料对照或无直接依据。无直接依据不能采纳描述，资料对照须登记资料来源。选择与理由均由后端校验；这些检查验证记录是否完整、一致，不能鉴别填写者是否说实话。卡片说明本次图像判断范围，不标记为专业结论。

补充文字默认只保存在工作文件。要写入卡片须勾选“将补充说明写入观察卡”；“其他理由”的自定义理由必须填写并展示。旧暂缓记录恢复后显示“本图无法判断”，旧初稿与人工修订保持独立，导出前重新选择相应理由。新客户端发送 evidence_version=2；后端继续接受 evidence_version=1 与更早输入。

本次验证了 10 项观察卡回归测试、1440/390 像素浏览器操作、实图单页导出及重新打开。原工作台 47 项测试完成，其中 4 项因测试进程未加载本地模型而跳过；此前实际 LaMa 演练记录另见下文。最长旧格式输入仍能以 9 pt 正文排入一页，超出承载量的新记录会给出精简提示。

## 真实壁画演练

examples/guangsheng-mural.jpg 是广胜寺《药师佛法会图》的缩小摄影图。作品与图像出处、权利说明和指纹见 examples/source.json。该图保留原有可见状态，缩小至 2000 × 970 像素供浏览器使用。

开发实测通过当前已配置的 DeepSeek Flash 接口取得三处观察初稿，人工保留两处用于单页观察卡。用 LaMa 对右下方一处小范围做数字试补，983 个处理像素，范围外变化 0，实测推理约 3.3 秒。已从界面导出一页观察卡、一页修复说明及前后对照图。模型原始初稿、开发测试填写的复核与建议修订分开留存。此例记录的是一次功能测试，缺损成因和恢复内容仍待专业核实。

运行环境若在 sample/real-mural.json 放入该次工作进度，首页会出现“打开真实壁画示例”，访问 /?trial=real 可直接查看，恢复后须重新核对再导出。全屏对照使用铺满视口的原生 dialog，局部窗口按实际处理像素定位，并有异步更新顺序校验。普通裁片查看继续保留独立窗口。
