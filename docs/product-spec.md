# 壁画智护 · 参赛产品需求

规划基线为 2026 年 11 月 20 日。本文列出拟交付能力与验收目标。正式成果在收到对应阶段的命题材料后制作。

2026年11月21日已接入 SQLite 工作档案与专业文献建议，具体实现及边界见 [决策0002](adr/0002-sqlite-and-reference-backed-advice.md)。

## 1. 作品定位

参加北京市大学生“人工智能+”阿里云壁画赛题。使用者是做图像观察、资料核对和虚拟修复的参赛队员。评委应能选定原图上一处痕迹，看到它为什么值得关注、AI 提了什么、队员修改了什么，以及为什么选择干预或保留。专业保护判断由有资质的人员复核。

把现有壁画工作台作为工程底座。借骨鉴的局部证据与著录方式，借北齐的区域标注与版本复核方式。面向评委的三个视图是原图与局部、区域证据与人工修订、正式输出预览。使用同一个区域编号贯穿三者。

## 2. 赛事决定交付顺序

页码按赛题 PDF 文件页计，含封面。讲解视频总长约 3 分 59 秒，示意画面自行标注为 AI 生成。正式输入取自赛事发放材料。

| 阶段 | 规定材料与操作 | 排名和设计取舍 |
|---|---|---|
| 高校推荐 | 按本校办法参加选拔。市级安排要求 11 月 7 日前初始报名、11 月 25 日前完成校内选拔及推荐 | 先确认本队报名及推荐状态，向本校联络人核对校内截止点 |
| 企业线上 | 企业提供 2–3 张未标注原图及场景说明。原图上标 1–3 处，给 1–2 条有依据和风险的建议。交一页观察卡 PDF 和至多 2 分钟的真实操作视频 | 本题附件明确线上排一、二、三等奖，前 10 队进现场。同分优先看结果质量、AI 能力运用，其后是问题理解、规范合规、创新与实用 |
| 阿里云现场 | 两天。用新发的 1 张受损图、1 页背景和少量参考，在千问办公完成分析、方案、虚拟修复及过程记录。AI 仅用赛事允许的百炼能力。提交成果图、对应对比图和单页修复说明，现场演示 | 第二天上午提交并冻结环境。展示答辩 15 分钟、问答 15 分钟；若用幻灯建议至多 10 页。现场前三获总决赛推荐。平分先比修复质量，再比方法与工作流、依据风险与人工复核 |
| 总决赛 | 一页决策框架或思维导图、方案陈述、专家问答 | 用新证据或相互矛盾的参考检验队伍能否修改决定。具体任务以组委会发布为准 |

## 4. 用户需求与验收

| 优先级 | 谁在什么情况下要做什么 | 完成时能观察到的结果 |
|---|---|---|
| P0 线上 | 操作员导入原图、场景和出处 | 保留原件、来源、使用范围及尺寸；界面预览可回指原件 |
| P0 | 队员调用一次允许使用且已披露的视觉工具 | 区域初稿、时间、实际模型或工具名称和响应状态留档；调用失败明确提示并可重试 |
| P0 | 复核队员从原图选中 R1，在同处放大核对 | 原图编号、局部和卡片同步定位；缩放、旋转校正后仍指向同一位置 |
| P0 | 复核队员区分可见现象、解释和缺少的资料 | 每条观察列出可见特征与另一种可能性；未能判断的原因可直接填写 |
| P0 | 队员补充出处，或只用图像作判断 | 可引用原图局部、赛事背景页、授权参考片段。每条建议列区域、依据、风险；允许明确写缺少参考 |
| P0 | 复核队员接受、修改或撤销 AI 建议 | 初稿和最终文字都可查看，保存修改理由。可否决误报并从正式图上移除 |
| P0 | 报告员导出同一次操作的线上成果 | 一页可读 PDF 含原图缩略图、编号区、观察、建议、风险、人工复核要求、素材与工具来源；超长内容提示精简，关键文字无截断 |
| P0 | 录屏队员用同一案例演示 | 视频可打开、≤120 秒，实际调用、选区、至少一次真实核对和导出可见；PDF 中编号、文字和视频末帧一致 |
| P1 现场 | 操作员拿到新题，按赛事手册在千问办公建立任务 | 平台内留有从新原图、背景和参考到区域分析、方案、候选图、复核的真实过程；使用的百炼能力逐项与现场清单核对 |
| P1 | 制图员处理有依据的一处，保留有争议的另一处 | 修复区域与观察框区分。记录选色、走线和纹样依据；能解释哪些区域原样保留以及依据缺口 |
| P1 | 复核队员在同一局部对比原件和候选 | 同视野、同尺度，先检查色彩、边缘和纹样连续性，再检查目标区外变化。可拒绝候选并回到原件 |
| P1 | 报告员核对现场三件成果并冻结 | 成果图、前后对比图、单页说明能独立打开；说明列 AI 参与、依据、不确定性、风险和复核点，能回查对应的平台记录 |
| P2 决赛 | 答辩队员接到相互矛盾的参考 | 一页列出冲突依据、可选处置、代价、当前选择、改判条件；追问时能指出新证据将改变哪个区域 |
| 后续 | 队员回看训练案例与版本 | 按档案编号恢复区域、依据、复核和候选，既有手工保存的工作文件支持导入；档案库可在核心提交链稳定后开发 |

**一个用来设计交互的例子**：R1 边缘出现细暗线。若线条穿过不同色块，记下这项观察；如果也可能是原笔线，保留两种解释。参考资料能支持的若只有纹样走向，修复方案就只讨论走向。不能据此确定原始颜料，也不能推断缺失人物的面部。此例为产品设计情境，正式作品引用当次原图和真实记录。

### 本次取舍与观察卡版式

按最新交互要求，区域结论使用“采纳描述／修改后采纳／不采纳／本图无法判断”四个按钮，理由随所选结论显示为选项。当前操作者完成选择，不设置等待其他审核人的待核验状态。“本图无法判断”本身就是受限于输入信息的最终记录。

采纳与修改后采纳需要登记图像或资料依据；只有个人意见不能采纳。修改后采纳应有实际文字变化，资料相符应有资料出处。自定义补充文字默认留在工作文件，操作者明确选择后才进入卡片；使用“其他理由”时必须写明理由。程序校验选项和记录的一致性，无法仅凭文字判断填写者是否说实话，也不将勾选声明标为专业认证。

一页 PDF 使用嵌入的宋体，主标题、章节标题、正文和来源采用不同字号。原图与区域详图连接同一编号；区域观察与依据、建议与风险分别成表。AI 原文与人工修订区分展示，未采纳内容明确标记。本卡的适用范围是原图可见信息与列明资料，不能由此确证材质与成因。

## 5. 技术栈与交付约束

- 线上首版沿用 Python 3.12、Flask、浏览器 JavaScript 与 Canvas，Pillow、NumPy、OpenCV 做裁切、坐标与像素比较，ReportLab 输出中文单页 PDF。保留现有工作进度导入导出。
- 单机档案已采用 Python 自带 SQLite 保存案例版本、引用和文件索引，原图/掩膜/结果按指纹保存为私有文件；编辑自动保存，保留 JSON 导入导出。不同页面对同一版本写入时提示冲突，历史版本以副本打开。
- 观察卡提供1–2条有文献依据的保护、数字展示或公众传播建议。行动和风险从逐条核对的模板选择，本图依据单独填写；页内列明文献编号、章节或条款和原文链接。资料集为两部专业图书与四份机构准则，未使用未读全文的知网论文。
- 线上视觉观察可沿用实测过的接口，也可使用符合授权的百炼视觉模型，按真实调用披露。现场使用赛事千问办公和当场授权的百炼能力，默认让比赛闭环在平台内独立成立。具体模型 ID、图像编辑能力、额度和平台导出方式在核验后登记。
- 如现场规则和操作手册允许，另用无模型通用库做排版、配准检查和像素差计算，并披露库名与用途。辅助程序使用独立入口与依赖清单，无调用模型、载入权重或恢复训练结果的路径。无法确认时直接在指定平台完成交付。工作台日志用于对照，平台原始记录另存。
- 服务器端校验正式导出所用区域、版本和复核状态。不保存密钥到报告或档案。复核后改动区域、依据或候选使旧复核失效。原件永久保留，换图后开启新档案。

## 6. 怎么检验效果

主验收入口为“导入一张新图，完成一次真实操作，打开正式导出”，并逐项回看证据。沿用工作台已有的 PDF 单页、掩膜外比较、恢复与来源校验测试。下列阈值是内部验收目标。

1. **线上质量盲读**。两名队友各自只看观察卡，指出每个区域在原图的位置、看到的现象、建议依据与复核点。任何一处找不到、两人把推测读成定论或出处打不开，重做该条。检查 1–3 个区域、1–2 条建议和来源齐全。
2. **真实演示**。从空白案例操作并录屏，目标 105–115 秒。建议 0–15 秒展示原图来源，15–45 秒展示真实 AI 操作与选区，45–80 秒放大一处、解释并修正，80–110 秒展示建议、风险和打开的 PDF。慢请求如实标明等待或剪辑，保留原录屏。拒绝用早先截图拼成新调用。
3. **候选质量**。同一处导出原图、掩膜和候选。若用无损 PNG 局部合成，按统一方向和色彩空间比较解码像素，产品目标为掩膜外改变数为零。开放式模型候选先核对尺寸、位移、伪影和区域外变化，再复核是否采纳。赛事要求的是非目标区保持合理，零变化是我们对局部合成的自定标准。
4. **异常演练**。无参考时可记录缺口、误报可撤销、重新编辑须复核、导出时检查必填项。用另一台设备打开两个阶段的 PDF 与图片。现场用指定平台实测一次新图流程；账号或网络故障按现场统一办法登记、重试。
5. **总决赛问答**。另一名队员临时给出一条相反参考，答辩者当场修改同一页中的取舍，解释是否撤回此前候选。原决定、变动原因都能找到。

## 7. 执行顺序

| 时间安排 | 负责人建议 | 退出条件 |

| 晋级前并行演练 | 平台操作员与图像复核员 | 熟悉千问办公入口和官方流程，准备空白字段、对比方法与答辩问题；获发赛事账号后核验授权清单 |
| 现场第一天、第二天上午 | 全队 | 第一天完成分析、候选、比对与复核；次日上午复查、提交并冻结。15 分钟陈述可按题材依据 3 分钟、操作与比对 8 分钟、复核结论 4 分钟分配 |

时间紧时先交付线上卡片与录像。暂缓博物馆管理后台、预算/材料/权限体系、3D、自动知识抓取、模型训练和大规模数据库。赛题未提供病害真值或统一标准图，训练图上的像素指标只用于发现工程回归。获奖由正式材料和评审决定。
