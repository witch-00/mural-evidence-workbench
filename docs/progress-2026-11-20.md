## 已完成

| 模块 | 当前效果 |
|---|---|
| 图像导入 | 支持 JPG、PNG、WebP 与 JSON 工作文件；导入新图片后保留“图像与资料”展开，便于填写来源和授权 |
| 工作区 | 朱红与米白配色，宋楷字体；顶栏导航、新标志与题句；原图与区域观察同屏，右侧独立滚动 |
| 局部查看 | 区域定位图包含周边与标记框；原图裁片可缩放、拖动，关闭按钮固定可见 |
| 修复入口 | 自动补全、借用原图、细缝填色、百炼重绘四个按钮；其他算法集中在展开项，保留旧工作文件的方法编号 |
| 修复对照 | “放大修补处”与“看整幅图”使用不同视野；全屏对照铺满窗口，支持分界线、缩放和拖动 |
| 本次结论 | 采纳描述、修改后采纳、不采纳、本图无法判断四个按钮，各有理由选项；不设置等待其他审核人的状态 |
| 内容取舍 | 采纳须有依据，修改后采纳须实际改文；无直接依据不能采纳。补充文字默认保存在工作文件，勾选后才进入卡片 |
| 观察卡 | 嵌入宋体，章节分级，观察与依据、建议与风险成表；移除页眉来源图例，单页导出并保留来源和 AI 参与记录 |
| API 配置页 | 朱红与宋体，宽表单配步骤说明；测试与保存并排，默认模型设置可展开；沿用原有测试通过后保存机制 |
| 配置兼容 | 将本机代理兼容修复及测试保存为独立补丁；仅对明确配置的域名允许代理地址池，继续校验 TLS 与目标地址 |

## 运行与恢复

当前实际使用的是已有壁画工作台与本仓库增量的集成版本。本仓库提供可公开的新增模块、页面、资源、测试及补丁；原工作台验证基线为 `cf2be17`。接入步骤见 [integration/README.md](../integration/README.md)。

当前电脑的 Linux 工作副本在 `/mnt/e/mural-lab/runtime/competition-preview`。本地案例工作文件、上传图像、模型权重与 API 凭据按原设置继续保存在电脑上。公开仓库保存代码进度及授权演练成果；浏览器尚未导出的个人编辑可通过“保存工作进度”另存。

当前仍使用 JSON 保存工作进度，未接入数据库与 RAG。原图、AI 初稿、人工修订、本次结论、修复掩膜与候选结果可随工作文件保存和恢复。
