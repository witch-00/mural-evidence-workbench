# 0002 · SQLite 档案与逐条文献建议

日期：2026-11-21。状态：已实现。

## 存储

采用 Python 标准库 sqlite3。SQLite 保存案例元数据、不可变版本、图像索引与建议引用；原图、掩膜和结果按 SHA-256 保存为私有文件，同图去重。先完成图像临时写入、刷新与原子替换，再在一个事务中登记版本和关系。失败时回滚元数据，之前的版本继续可读。读取时核对文件指纹；由完整工作文件再次保存可以恢复受损图像文件。

默认目录为集成工作副本的 `data/case-library/`，可由 `MURAL_DATA_DIR` 指定。数据库文件为 `workbench.sqlite3`，图像在同目录 `assets/`。使用 SQLite 默认回滚日志与 FULL 同步，不依赖 WSL 挂载盘上的 WAL 共享内存文件。每次操作使用独立连接、外键校验与写事务，保存操作须携带打开时的版本号，发生冲突返回409。

浏览器编辑后延迟自动保存；显示保存状态，提供显式保存、案例列表、历史版本与另存副本。历史版本以副本打开，避免覆盖最新内容。普通主页可从浏览器中保存的上次档案编号恢复；示例 URL 明确打开示例。浏览器只记档案编号，图像和正文存于本机档案库。JSON 导入、导出仍使用同一项目数据结构，版本1–3保持可读。

表为 cases、case_versions、assets、version_assets、reference_sources、recommendation_citations。每个案例版本保存当次引用的完整书目与定位快照，避免以后更新目录时改写历史引用。实际数据库、图像、凭据和个人案例不进入公开 Git 历史。

## 文献与建议

`references/catalog.json` 保存6个已读全文来源和6条逐条核对的建议模板，研究记录见 `docs/research/recommendation-sources-2026-11-21.md`。每条模板包含行动、专业原则、风险、适用条件、限制、源ID和具体条款，三类分别为保护、数字展示、公众传播。

一页卡允许选择1–2条。行动与风险使用已核对模板，操作者另填本图可见依据、选择目标区域。修改后的自由文字可以存档，但不能继续借用原模板的核验状态；新格式正式导出会要求重新选择适用模板。服务端重建文献编号和定位，不接受客户端伪造的书目或专家认证字段。引用表示专业原则可追溯，不表示机构对平台或本案进行了认证。

模型观察提示词获得同一目录与模板，禁止编造书目或从原则反推病害；模型未返回有效引用时，操作者可以从文献选项中补齐。文献原则与本图依据分开显示。PDF 同页列引用编号、条款与书目，并提供原文链接。旧客户端未带 reference_version 时保留原格式的导出兼容性；新界面发送 reference_version=1 并执行文献门槛。

此次没有接入向量数据库、RAG 或自动网络抓取。目录是人工核对后发布的有限资料集，便于说明每一条建议到底依据哪一处原文。
