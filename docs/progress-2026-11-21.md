# 2026 年 11 月 21 日 · SQLite 与文献建议

## 已实现

1. 接入真实 SQLite 档案库。编辑后自动保存，提供保存状态、打开档案、历史版本和另存副本；普通主页可恢复上次档案。历史版本作为副本编辑，多个页面修改同一版本时阻止静默覆盖。
2. 图像独立保存并按指纹去重；SQLite 记录案例、版本、图像索引与每条建议的文献快照。保留 JSON 工作文件导入、导出，不将图片与 API 配置写入公开仓库。
3. 核对两部专业图书和四份机构准则的全文、版本、章节及页码，形成6条建议模板，保护／数字展示／公众传播各2条。可选择1–2条进入观察卡。
4. 行动、专业原则和风险与具体原文对应，本图依据单独填写。正式导出要求使用已核验模板；随意改写的行动或风险不能继续套用原模板引用。自拟初稿仍可保存。
5. AI 观察提示词获得同一来源与模板目录，服务端丢弃不存在的模型引用编号；界面可从资料库补选。引用不作为某一病害或机构认证的证据。
6. 单页宋体卡列本图依据、文献编号与具体定位，页脚提供书目和可点击全文链接。
7. 档案栏与档案窗口增加“新建壁画档案”，老师可直接选另一幅图片。导入前保存当前档案，新图独立建档并展开来源填写区；取消选图或保存失败时保留当前内容。已验证原档保留、两个入口、保存失败保护及1440/390像素布局。
8. “图像与资料”改为始终显示的资料面板，导入、恢复及重新打开档案均不再折叠。局部虚拟修复标题下新增区域按钮，与上方观察区同步；切换时直接显示该局部，保留原掩膜与结果，未涂抹区域明确说明，不再沿用其他区域的修补位置。
9. 建议适用范围改为“整幅画面／R1 局部／R3 局部”等可见单选按钮，并解释整体与局部的区别。未选或关联区域被删除时，导出会定位到对应建议，显示说明并聚焦选项；选择后清除错误，并要求重新确认本次记录。

## 本机数据与接续

默认数据库位于集成副本 `data/case-library/workbench.sqlite3`，图像在同目录 `assets/`；可以用 `MURAL_DATA_DIR` 指定持久目录。数据库、图像及案例数据已排除在 Git 之外；完整备份应包含数据库和图像目录，单份案例可导出 JSON。

本次没有部署独立数据库服务、向量库或 RAG。资料集是已核对后随代码发布的目录，实际案例保持在本机。SQLite 的结构与文献边界见 [决策0002](adr/0002-sqlite-and-reference-backed-advice.md)。
